# План до полноценного продукта

Принцип: **ничего не считаем готовым, пока это не видно и не проверено на настоящем Windows 11**. Для этого в CI (windows-latest)
есть смоук-запуск оболочки со скриншотом реального рабочего стола; результат смотрим глазами, а не по «ready: True».

## 0. Где мы сейчас (честно)

| Область | Состояние |
|---|---|
| Архитектура, протокол, IPC, безопасность | Готово, покрыто тестами (Core 2180, UI 1081, Host 253) |
| Core-логика (док, поиск, Mission Control, виджеты, настройки) | Готова и протестирована на фейках портов |
| Windows-слой (Win32/WinRT) | Собирается; интеграционные тесты на windows-latest зелёные, кроме одного нестабильного (`StatusDebouncer`) |
| Запуск на реальной машине | Процесс стартует, поверхности подключаются. **Док и меню-бар на экране не видны** (главный блокер) |
| Известные дефекты | Чтение громкости (`CoreAudioEndpoint`, RCW), конфликт хоткея Ctrl+Alt+M, WebView композиционный контрол (обновлён, нужна проверка), WIC-санитайзер иконок не реализован |

## Фаза 1. Видимая оболочка (блокер, делаем первой)

Цель: на реальном Windows 11 виден док внизу и меню-бар сверху, панель задач прячется **только** когда они реально видны.

1. Скриншот-CI с показанными окнами (BETTERWINDOWS_SMOKE_SHOW) → найти, почему окна не видны (вырез `SetWindowRgn`, `surface.shape`, композиционный WebView, подложка DWM).
2. Починить рендер; запасной путь «layered» (`BETTERWINDOWS_SURFACE_TECH`) и классический WebView, автоматический откат при сбое.
3. Условие скрытия панели задач: не «ready», а «окно показано, форма применена, пиксели есть». Автовозврат панели, если оболочка закрылась или завис UI.
4. Несколько мониторов, смешанный DPI, смена разрешения, подключение/отключение монитора, спящий режим.
5. Критерий готовности: скриншот CI + ручной чек-лист на двух машинах.

## Фаза 2. Основные функции, каждая «от начала до конца»

- **Док**: закрепления, запущенные приложения, индикаторы, увеличение при наведении, запуск, переключение/сворачивание окон, контекстное меню, перетаскивание, прыжок при запуске, корзина, автоскрытие, позиция (низ/лево/право).
- **Меню-бар**: яблочное меню, меню активного приложения, часы, статусные иконки (звук, сеть, Wi-Fi, Bluetooth, батарея, трей), Центр управления, календарь, медиа.
- **Spotlight**: приложения, файлы, окна, калькулятор, команды, настройки, веб; предпросмотр; недавние.
- **Launchpad**: сетка приложений, папки, поиск, страницы.
- **Mission Control**: рабочие столы, миниатюры окон, перенос окон между столами, создание/удаление столов.
- **Рабочий стол**: виджеты (погода, напоминания, часы, заметки), ярлыки, слой на рабочем столе.
- **Горячие углы и жесты**, хоткеи (с учётом конфликтов и переназначением из настроек).

## Фаза 3. Настройки (полное окно)

Разделы: Общие (язык, тема, автозапуск), Док, Меню-бар, Spotlight, Mission Control, Рабочий стол/виджеты, Горячие клавиши и углы, Панель задач (видима / автоскрытие / скрыта), Внешний вид (цвета, прозрачность, анимации, Reduce Motion/Transparency), Дополнительно (диагностика, логи, сброс, экспорт/импорт).
Требования: применение «на лету», валидация (уже есть), откат к умолчаниям, окно с Mica и тёмной шапкой, русский и английский.

## Фаза 4. Интеграция с системой

Звук (громкость, устройства), яркость, сеть/Wi-Fi, Bluetooth, батарея, медиа-сессии, трей-иконки, уведомления, виртуальные рабочие столы (документированный путь, внутренний API за флагом), автозапуск, режимы панели задач, питание (сон/блокировка/выключение), буфер обмена.
Известные дефекты из логов: чтение громкости (`InvalidComObjectException`), IPolicyConfig (проверить vtable), санитайзер иконок через WIC.

## Фаза 5. Надёжность и безопасность

- Guardian и журналы восстановления: проверка после убийства процесса, краша, выхода из системы.
- Режим безопасности (3 неудачных старта) и сообщение пользователю с путём к логам (уже добавлено).
- Диагностика: `--diagnose`, `--smoke`, экспорт отчёта.
- Безопасность по `docs/IPC.md` §14: недоверенный UI, политика путей/URL, лимиты — тесты уже есть, повторный аудит перед релизом.
- Закрыть нестабильный тест `StatusDebouncer`.

## Фаза 6. Качество

- Визуальные регресс-скриншоты в CI для дока, меню-бара, Spotlight, Launchpad, Mission Control, настроек (светлая/тёмная тема, ru/en).
- Ручной чек-лист (в `docs/DECISIONS.md`) на реальных машинах: 1 и 2 монитора, 100%/150% DPI, Windows 11 22H2/23H2/24H2.
- Производительность: запуск < 2 с, простой < 1% CPU, 60 fps анимации, потребление памяти.
- Доступность: клавиатура, фокус, `aria-*`, высокий контраст.

## Фаза 7. Релиз

Установщик (MSIX или Inno Setup), подпись кода, автообновление, страница релизов, README с гифками, политика приватности (всё локально, сеть только для погоды), лицензии зависимостей, версионирование и changelog.

## Порядок работ и контроль

1. Фаза 1 целиком → показываю скриншоты из CI.
2. Фазы 2–4 идут по функциям: каждая закрывается тестом, скриншотом и записью в чек-листе.
3. Фаза 5–7 параллельно, как только оболочка видима.
4. Каждый шаг: сборка, тесты Core/UI/Windows, смоук-скриншот, только потом коммит в `master`.
