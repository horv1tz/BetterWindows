# Архитектурные решения (ADR, кратко)

Журнал решений, которые отличаются от первоначального плана или неочевидны. Каждое решение принято после технической проверки;
там, где проверка возможна только на настоящем рабочем столе Windows, это отмечено.

| # | Решение | Почему | Статус проверки |
|---|---|---|---|
| 1 | **Explorer остаётся оболочкой.** Мы прячем штатную панель задач (режим `ABS_AUTOHIDE` + `SW_HIDE`), а не заменяем `explorer.exe`. | Заменять shell хрупко: ломается при обновлениях Windows, теряются уведомления, Win+X, тач‑клавиатура. | Логика покрыта тестами; поведение на реальном рабочем столе проверяется вручную (чек‑лист ниже). |
| 2 | **Область уведомлений (трей) сторонних приложений не размещается.** `ITrayHost.IsSupported = false`. Вместо этого в меню есть «Показать панель Windows». | Пока Explorer работает, приложения шлют `Shell_NotifyIcon` в его собственное окно `Shell_TrayWnd`; второй хост их не получит. Рабочий обход (недокументированный `ITrayNotify`) зависит от сборки Windows. | Выявлено независимым ревью контрактов. |
| 3 | **Ресурсы UI раздаются через `WebResourceRequested`, а не через `SetVirtualHostNameToFolderMapping`.** Статические файлы и `/dyn/*` отдаёт сам хост. | Для виртуально смапленных хостов `WebResourceRequested` не срабатывает (документированное поведение WebView2), поэтому иконки и миниатюры из памяти не работали бы. | Ревью + документация Microsoft. |
| 4 | **Размытие фона — через `DWMWA_SYSTEMBACKDROP_TYPE` + `SetWindowRgn`, а не `DwmEnableBlurBehindWindow`.** UI сообщает панели (`surface.shape`: `rects` и `hitRects`). | `DwmEnableBlurBehindWindow` не даёт размытия с Windows 8. Системный фон применяется ко всему окну, поэтому форму задаёт регион окна. Если хост не умеет ограничить фон областями (`glassOverflow=false`), UI держит весь контент дока внутри стеклянной панели. | Требует проверки на реальной Windows 11 (спайк A). |
| 5 | **Прозрачность без слоёв:** предпочтительно окно без `AllowsTransparency` с `DwmExtendFrameIntoClientArea(-1)`. | Слойные окна (`WS_EX_LAYERED`) не совместимы с системными фонами DWM. | Требует проверки на реальной Windows 11. |
| 6 | **Миниатюры окон — лениво через `/dyn/thumb`,** с кэшем «последний удачный снимок». | `PrintWindow` не снимает окна на других виртуальных столах и свёрнутые окна; их показываем из последнего снимка, сделанного, пока окно было активным. | Логика тестируется; захват — на Windows. |
| 7 | **Виртуальные рабочие столы без внутренних COM‑интерфейсов:** список из реестра, переключение через `Win+Ctrl+←/→`, перенос окон — только публичный API (для чужих окон может быть недоступен). | Внутренние GUID меняются между сборками Windows. | Тесты на Windows‑CI. |
| 8 | **Окно настроек — пятая поверхность** (`#/settings`), а все всплывающие меню рисует оверлей. | Меню должны выходить за пределы маленьких окон дока и строки меню и закрываться по клику вне их. | Проверено на моке в Chromium. |
| 9 | **Один контракт — один источник правды:** `protocol/*.json` → генерируются C#, TypeScript и справочник. | Параллельная разработка без расхождения форматов. | CI проверяет свежесть. |
| 10 | **Логика в кроссплатформенном Core за интерфейсами‑портами.** | Её можно тестировать здесь, на Linux; Windows‑слой остаётся тонким. | 20+ тестов базы, сотни тестов потоков. |
| 11 | **Сторожевой процесс** `--watchdog <pid>` восстанавливает панель задач, даже если основной процесс убит через `taskkill /f`. | Иначе после принудительного завершения панель остаётся скрытой до следующего запуска. | Требует проверки на Windows. |
| 12 | **Размещение рабочего стола** (WorkerW) — только в одном месте, `IDesktopIconsController`. | Структура окон рабочего стола меняется между сборками (24H2); одна копия логики проще чинить. | Требует проверки на Windows 11 24H2. |

## Чек‑лист ручной проверки на реальной Windows 11

1. Запуск: панель Windows скрылась, строка меню и док на месте, окна приложений не уходят под док.
2. `Ctrl+Alt+Shift+T` показывает/скрывает штатную панель; `Ctrl+Alt+Q` завершает работу и возвращает панель.
3. `taskkill /f /im BetterWindows.exe`: панель возвращается сама (сторожевой процесс).
4. Клик по доку не отбирает фокус у активного окна; имя приложения в строке меню не превращается в «BetterWindows».
5. `Alt+Space`: Spotlight; `Ctrl+Alt+L`: Launchpad; `Ctrl+Alt+M`: Mission Control; Esc закрывает.
6. Мультимонитор с разным масштабом (100% и 150%): док и меню на своих мониторах, ничего не размыто.
7. Полноэкранная игра/видео: док и меню скрываются на этом мониторе и возвращаются после выхода.
8. Перезапуск Explorer (`taskkill /f /im explorer.exe` + запуск): панель остаётся скрытой, поверхности живы.
9. Запуск с `--diagnose`: отчёт без критических ошибок. Запуск с `--safe-mode`: ничего не скрывается.
