# BetterWindows

Оболочка в стиле macOS поверх Windows 11: док, строка меню, Spotlight‑поиск,
Launchpad, Mission Control, виджеты рабочего стола. Windows остаётся операционной
системой, Explorer остаётся shell — заменяются только видимые элементы интерфейса.

Стек: .NET 8 + WPF + WebView2 (хост и системные сервисы), TypeScript + Vite + Svelte (UI).

## Документация

- [docs/PLAN.md](docs/PLAN.md) — цели, границы, анализ референсов, дорожная карта по фазам,
  риски, что нужно для старта, открытые вопросы.
- [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) — архитектура: окна‑хосты и WebView2, IPC,
  сервисы и конкретные Windows API для каждой функции, жизненный цикл, сборка и релиз.
